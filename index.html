        How this updates. A scheduled task runs every morning at 06:40 Regina time. It scans the three regions, matches each posting to existing entries, and commits the result to data/jobs.json, the only file that changes daily. A new job gets first_seen = today. A job that shows up again keeps its first_seen, gets today as last_seen, and its sighting count goes up. This page reads that file each time it loads. The intelligence report is refreshed on Mondays.
